# Security policy

## Supported versions

Only the [latest release](https://github.com/kristof-mattei/autoheal-rs/releases/latest) receives security fixes. Fixes are not backported to older releases.

## Reporting a vulnerability

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/kristof-mattei/autoheal-rs/security/advisories/new). Do not open a public issue.
